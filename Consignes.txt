Tu es un développeur full-stack expert. Je veux créer TrackMyApps, un SaaS de suivi de candidatures (stages, alternances, jobs étudiants) spécialement conçu pour les étudiants.
Contexte et objectifs
Créer une application web moderne permettant aux étudiants de suivre efficacement toutes leurs candidatures, de ne manquer aucune relance, de préparer leurs entretiens et d'analyser leur performance. L'application doit être intuitive, rapide, motivante et mobile-friendly.
Stack technique imposée
Frontend :

React 18+ avec TypeScript
Tailwind CSS pour le styling
Shadcn/ui pour les composants UI réutilisables
React Router v6 pour la navigation
TanStack Query (React Query) pour la gestion des données et cache
Zustand pour l'état global léger
React DnD Kit pour le drag & drop du Kanban
Recharts pour les graphiques et analytics
React Hook Form + Zod pour les formulaires et validation
Date-fns pour la manipulation des dates
Lucide React pour les icônes

Backend :

Node.js 18+ avec Express.js
PostgreSQL comme base de données
Prisma comme ORM
JWT pour l'authentification
Bcrypt pour le hashing des mots de passe
Multer pour l'upload de fichiers
Node-cron pour les tâches planifiées (rappels, notifications)
Nodemailer pour les emails (notifications, relances)
Express-validator pour la validation des requêtes

Infrastructure :

Docker et Docker Compose pour la conteneurisation
Variables d'environnement pour la configuration (.env)
AWS S3 ou solution locale pour le stockage des fichiers (CV, lettres)

Schéma de base de données Prisma
prisma// schema.prisma

generator client {
  provider = "prisma-client-js"
}

datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}

model User {
  id              String   @id @default(uuid())
  email           String   @unique
  password        String
  firstName       String
  lastName        String
  school          String?
  graduationYear  Int?
  field           String?
  avatarUrl       String?
  resetToken      String?
  resetTokenExpiry DateTime?
  
  // Preferences
  emailNotifications Boolean @default(true)
  relanceFrequency   Int     @default(7) // days
  
  createdAt       DateTime @default(now())
  updatedAt       DateTime @updatedAt
  
  applications    Application[]
  documents       Document[]
  reminders       Reminder[]
  interviewPreps  InterviewPrep[]
  companyReviews  CompanyReview[]
  
  @@map("users")
}

model Application {
  id              String   @id @default(uuid())
  userId          String
  user            User     @relation(fields: [userId], references: [id], onDelete: Cascade)
  
  companyId       String?
  company         Company? @relation(fields: [companyId], references: [id])
  companyName     String   // Denormalized for flexibility
  
  position        String
  jobType         JobType
  location        String
  status          ApplicationStatus @default(SENT)
  
  applicationDate DateTime @default(now())
  jobUrl          String?
  salary          String?
  notes           String?
  
  cvUsedId        String?
  cvUsed          Document? @relation("ApplicationCV", fields: [cvUsedId], references: [id])
  
  lmUsedId        String?
  lmUsed          Document? @relation("ApplicationLM", fields: [lmUsedId], references: [id])
  
  lastRelanceDate DateTime?
  interviewDate   DateTime?
  decisionDate    DateTime?
  
  createdAt       DateTime @default(now())
  updatedAt       DateTime @updatedAt
  
  events          ApplicationEvent[]
  reminders       Reminder[]
  
  @@map("applications")
}

enum JobType {
  STAGE
  ALTERNANCE
  CDI
  JOB_ETUDIANT
}

enum ApplicationStatus {
  DRAFT
  SENT
  VIEWED
  INTERVIEW_SCHEDULED
  AWAITING_RESPONSE
  REJECTED
  ACCEPTED
  GHOSTED
}

model ApplicationEvent {
  id              String   @id @default(uuid())
  applicationId   String
  application     Application @relation(fields: [applicationId], references: [id], onDelete: Cascade)
  
  eventType       EventType
  eventDate       DateTime @default(now())
  notes           String?
  
  createdAt       DateTime @default(now())
  
  @@map("application_events")
}

enum EventType {
  CREATED
  SENT
  VIEWED
  RELANCE_SENT
  INTERVIEW_SCHEDULED
  INTERVIEW_DONE
  REJECTED
  ACCEPTED
  STATUS_CHANGED
}

model Document {
  id              String   @id @default(uuid())
  userId          String
  user            User     @relation(fields: [userId], references: [id], onDelete: Cascade)
  
  type            DocumentType
  name            String
  version         String?
  fileUrl         String
  fileName        String
  fileSize        Int
  mimeType        String
  
  isMain          Boolean  @default(false)
  
  createdAt       DateTime @default(now())
  updatedAt       DateTime @updatedAt
  
  applicationsCV  Application[] @relation("ApplicationCV")
  applicationsLM  Application[] @relation("ApplicationLM")
  
  @@map("documents")
}

enum DocumentType {
  CV
  LETTRE_MOTIVATION
}

model Company {
  id              String   @id @default(uuid())
  name            String   @unique
  sector          String?
  size            String?
  websiteUrl      String?
  
  averageResponseTime Int? // in days
  cultureTags     String[] // JSON array of tags
  hiringProcess   String?
  
  createdAt       DateTime @default(now())
  updatedAt       DateTime @updatedAt
  
  applications    Application[]
  reviews         CompanyReview[]
  
  @@map("companies")
}

model CompanyReview {
  id              String   @id @default(uuid())
  companyId       String
  company         Company  @relation(fields: [companyId], references: [id], onDelete: Cascade)
  
  userId          String
  user            User     @relation(fields: [userId], references: [id], onDelete: Cascade)
  
  rating          Int      // 1-5
  comment         String?
  position        String
  salary          String?
  wasHired        Boolean
  interviewExperience String?
  
  createdAt       DateTime @default(now())
  
  @@map("company_reviews")
}

model Reminder {
  id              String   @id @default(uuid())
  userId          String
  user            User     @relation(fields: [userId], references: [id], onDelete: Cascade)
  
  applicationId   String?
  application     Application? @relation(fields: [applicationId], references: [id], onDelete: Cascade)
  
  reminderType    ReminderType
  reminderDate    DateTime
  message         String
  isDone          Boolean  @default(false)
  
  createdAt       DateTime @default(now())
  
  @@map("reminders")
}

enum ReminderType {
  RELANCE
  INTERVIEW_PREP
  THANK_YOU_EMAIL
  FOLLOW_UP
  CUSTOM
}

model InterviewPrep {
  id              String   @id @default(uuid())
  userId          String
  user            User     @relation(fields: [userId], references: [id], onDelete: Cascade)
  
  question        String
  answer          String?
  category        String   // "general", "technical", "behavioral"
  
  createdAt       DateTime @default(now())
  updatedAt       DateTime @updatedAt
  
  @@map("interview_preps")
}

Points techniques importants
Authentification

JWT stocké dans localStorage (ou httpOnly cookie pour plus de sécurité)
Middleware backend pour vérifier token sur routes protégées
Refresh token (optionnel pour MVP, mais prévoir structure)
Expiration token : 7 jours

Upload de fichiers

Multer côté backend pour gérer les uploads
Validation : taille max 5 MB, types MIME autorisés (application/pdf, application/vnd.openxmlformats-officedocument.wordprocessingml.document)
Stockage local dans /uploads pour MVP (prévoir migration S3 future)
Nommage unique des fichiers : userId_timestamp_originalName

Gestion des dates

Tout stocker en UTC dans la base
Conversion en temps local côté frontend avec date-fns
Format d'affichage français : "dd/MM/yyyy" et "dd/MM/yyyy HH:mm"

Cron jobs pour rappels

Job quotidien (ex: tous les jours à 8h00) qui :

Scanne toutes les candidatures statut "Envoyée" sans réponse depuis X jours
Crée des reminders de type "RELANCE"
Scanne candidatures avec entretiens dans 3 jours
Crée reminders de type "INTERVIEW_PREP"


Job pour envoyer emails quotidiens de résumé (si activé par user)

Notifications in-app

Utiliser React Query avec polling ou WebSocket (optionnel pour MVP)
Badge de compteur sur icône "Rappels" dans le header
Toast notifications pour actions importantes (candidature créée, document uploadé)

Performance et optimisation

Pagination côté backend pour listes longues (20 candidatures par page)
Lazy loading des documents (ne pas charger tous les PDFs d'un coup)
React Query avec staleTime et cacheTime optimisés
Debounce sur les champs de recherche/filtres

Sécurité

Sanitization des inputs

CORS configuré correctement
Headers de sécurité (helmet.js)
Pas de données sensibles dans les logs

     # Setup database

     npx prisma db seed
     
     # Run app
     docker-compose up
